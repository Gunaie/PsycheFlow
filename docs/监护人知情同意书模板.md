## 一、项目介绍

【学校名称】（以下简称"学校"）拟使用 PsycheFlow 智能心理评估系统（以下简称"本系统"）开展学生心理健康筛查。

本系统通过**标准化心理量表施测 + AI 辅助对话 + 自动生成筛查报告**的方式，帮助学校心理老师了解学生心理健康状况。量表采用公开标准化工具（PHQ-A 抑郁筛查、SCARED 焦虑筛查、SDQ 长处与困难问卷、MHT 心理健康诊断测验）。

**特别声明：本系统非医疗器械，筛查结果不构成诊断，不替代专业诊疗/诊断/开药。** 如需诊断与治疗，请前往正规医疗机构精神科/心理科。

## 二、筛查内容与流程

1. 学生在机房或自带设备上，凭学校发放的**6 位筛查码**进入作答页面（可匿名），完成所选量表选择题（约 5-15 分钟）；
2. 系统自动计分并生成个人报告，报告含量表得分、维度剖析、发展建议；
3. 学校心理老师可在管理后台查看班级汇总统计与个案报告，用于安排后续心理课、团体辅导或个别关注；
4. 学生也可自愿使用 AI 倾诉对话功能（可选，不影响筛查）。

## 三、收集的信息与保护措施

**收集范围（最小必要原则）**：

| 信息 | 是否必填 | 用途 |
|---|---|---|
| 姓名、学号、年级、班级 | 均可留空（支持完全匿名） | 报告署名与班级统计 |
| 性别、年龄 | 可选 | 报告基本信息 |
| 监护人手机号 | 可选 | 仅危机转介时联系 |
| 量表作答数据 | 必填（测评本身） | 计分与报告生成 |
| 对话内容（如使用 AI 对话） | 自愿 | 仅用于回应与安全审计 |

**保护措施**：

1. 全程传输加密（HTTPS/TLS）；数据存储于学校指定服务器，**不用于任何商业目的，未经授权不向任何第三方披露**；
2. 不收集人脸、指纹、通讯录、相册、定位等与测评无关的信息；
3. 14 周岁以下学生个人信息按《个人信息保护法》第三十一条受**敏感个人信息特别保护**；
4. 涉及危机转介的记录以审计日志形式独立留存，可追溯、不可篡改；
5. 您可随时向学校申请**查阅、更正或删除**学生的相关信息；撤回同意后学校将停止其参与后续筛查。

## 四、危机情况打破保密的特别说明

当测评或对话中出现自杀/自伤/伤人等危机关键词（如"不想活了""跳楼""去死"），或抑郁量表自杀意念相关条目得分≥1 分时，**为保护学生生命安全，系统将打破保密限制**，按以下链路转介：

1. **校内**：学校心理老师 → 德育处 → 监护人；
2. **校外**：12355 共青团青少年心理热线（24 小时免费）→ 120 急救 → 110 报警（视危险等级）；
3. 每次危机命中均生成审计留痕，学校心理老师会第一时间与监护人联系。
