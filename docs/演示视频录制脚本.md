# 演示视频录制脚本（OBS · 3 分钟）

> 目标：给 GitHub README / 简历配套一段 3 分钟功能演示，突出「产品完整度 + 危机安全链路 + 工程质量」。
> 节奏原则：每个镜头 ≤ 25 秒；旁白可直接当口播稿，不想录音就只打字幕。

---

## 一、录前准备清单

### 数据准备（5 分钟）
- [ ] 前后端容器已启动（前端 http://localhost:5174）
- [ ] 运行 `cd backend && uv run scripts/screenshots.py` 造演示数据（教师/批次/学生/测评记录）
- [ ] 如批次列表有多次运行留下的旧演示批次：要么全删只用最新的，要么保留（多批次也真实）
- [ ] 手动记下：演示学生账号、教师账号、任一未完成批次的筛查码（学生侧现场凭码作答用）

### 环境准备
- [ ] 浏览器**无痕窗口**，1920×1080 全屏，缩放 100%，隐藏书签栏
- [ ] 关闭微信/QQ 等通知；任务栏自动隐藏
- [ ] 提前打开两个标签页：门户页（待登录态）、GitHub 仓库页（结尾用）
- [ ] 平滑滚动设置：录屏时段用鼠标滚轮缓慢滚动，报告页长图逐章展示

### OBS 配置（2 分钟）
| 项 | 推荐值 |
|---|---|
| 画布/输出分辨率 | 1920×1080 |
| 帧率 | 30 fps |
| 来源 | 「显示器采集」整个屏幕（方便切标签页） |
| 编码 | x264 / CBR 码率 6000-8000 Kbps |
| 录像格式 | MKV（防崩溃损坏，录完 `文件→录像重新封装` 转 MP4） |
| 音频 | 旁白用麦克风；不录音则把桌面音轨静音，纯字幕版 |

## 二、分镜脚本（总时长 3:00）

### 镜头 1 ｜ 0:00-0:12 ｜ 门户开场
- **画面**：停留门户页（横幅 + 学生端/教师端双卡）
- **操作**：鼠标从横幅缓慢移到双卡，分别悬停高亮
- **旁白**：
  > 这是 PsycheFlow，一个面向中小学生的校园心理健康筛查与 AI 陪伴系统。学生和老师从这扇大门各走各的世界。
- **字幕要点**：`四量表筛查 · AI 陪伴对话 · 教师批次管理`

### 镜头 2 ｜ 0:12-0:35 ｜ 学生作答
- **画面**：进入学生端 → 量表选择页 → 点开 PHQ-A
- **操作**：连续作答 4-5 题（每题点击后停 0.5 秒，让观众看清选项高亮和顶部进度条前进）
- **旁白**：
  > 学生端内置 PHQ-A、SCARED、SDQ、MHT 四套标准量表，逐题作答、实时计分。所有量表都有各自的选项档位和计分规则，含反向计分。
- **字幕要点**：`PHQ-A · SCARED · SDQ · MHT ｜ 实时进度`

### 镜头 3 ｜ 0:35-1:05 ｜ 报告展示（核心卖点 1）
- **画面**：交卷 → 历史报告页 → 打开报告详情
- **操作**：报告页**缓慢向下滚动**，依次停留：人员信息（真实姓名/测评用时）→ 测评结果 → **雷达图** → 发展建议；最后点「下载 PDF」弹保存框
- **旁白**：
  > 提交后生成六章结构的专业报告：从工具介绍、结果解读到个性化发展建议，多维度量表自动生成雷达图。报告可一键导出 PDF，排版由 WeasyPrint 服务端渲染。
- **字幕要点**：`六章结构（对齐 MHT 参考）｜ 雷达图 ｜ PDF 导出`

### 镜头 4 ｜ 1:05-1:35 ｜ AI 对话（核心卖点 2）
- **画面**：切到对话页 → 选人设「安慰姐姐」→ 发送"最近压力好大，睡不好"
- **操作**：让 SSE 流式回复完整打出（约 10 秒，不加速）；回复结束展示「知识来源」折叠卡片，点开一次再折上
- **旁白**：
  > AI 陪伴对话基于 LangGraph 多智能体链：先分诊意图，再按需推送量表或共情干预，回答流式输出。引用知识库时只做自然语言转述，来源卡片默认折叠。
- **字幕要点**：`Triage → Assessment → Intervention（SSE）｜ RAG 来源可折叠`

### 镜头 5 ｜ 1:35-1:52 ｜ 危机拦截（核心卖点 3，全片高潮）
- **画面**：同一对话框，输入"我真的不想活了"→ 回车
- **操作**：红色危机提示弹出的瞬间**停 3 秒**不动，让 12355 热线信息清晰可见
- **旁白**：
  > 关键安全设计：危机识别是前置的硬编码词表拦截，**不经过任何大模型**——零延迟弹出 12355 热线与转介链路，同时双向写入审计留痕。这条链路不依赖网络、不依赖模型，永远可用。
- **字幕要点**：`危机检测零 LLM ｜ 12355 ｜ 双重审计留痕`

### 镜头 6 ｜ 1:52-2:25 ｜ 教师端批次管理
- **画面**：切教师账号 → 管理后台批次列表 → 打开演示批次详情
- **操作**：详情页缓慢下滚：统计卡 → 施测进度条 → **危机升级名单（红色，含触发词与转介链）** → 严重度分布 → 按班级进度 → 学名单（点一次「报告」）；回到列表点一次「导出汇总 CSV」
- **旁白**：
  > 教师端按批次管理班级筛查：匿名凭码作答，谁完成了、谁触发了危机一目了然。危机学生单独成列，触发词和转介链直接写在页面上，导出 CSV 交 给心理老师归档。
- **字幕要点**：`匿名筛查码 ｜ 危机名单+触发词 ｜ CSV 导出`

### 镜头 7 ｜ 2:25-2:45 ｜ 工程质量卡（纯字幕 + 架构图/指标）
- **画面**：打开 GitHub 仓库页，滚到 README 的「质量与性能指标」表和架构图各停 3 秒
- **旁白**：
  > 工程侧：GitHub Actions 全绿；LLM 输出评估体系——意图分诊准确率 97.7%，危机拦截 100%，报告结构合规 100%；对话首 token 1.7 秒；云端故障自动降级本地 Ollama。
- **字幕要点**：`CI 全绿 ｜ eval 97.7%/100% ｜ 首 token 1.7s ｜ 三级降级链`

### 镜头 8 ｜ 2:45-3:00 ｜ 收尾
- **画面**：回到门户页底部合规声明，或 GitHub 仓库首页
- **操作**：静止 3 秒结束
- **旁白**：
  > PsycheFlow——非医疗器械，非替代专业诊疗，危机时刻请拨打 12355。仓库地址见简介。
- **字幕要点**：`非医疗器械 · 非替代专业诊疗 ｜ 12355`

## 三、录制与后期要点

1. **每个镜头单独录一段**（开始/停止录像），别一口气录 3 分钟——方便删掉失误重录单段
2. 鼠标动作放慢 20%，切页面后**先停 1 秒再说话**
3. 失误不用重录整段：停 2 秒，从当前镜头开头重来，后期剪
4. 后期：镜头 4 的流式回复可 1.5 倍速；镜头间硬切即可，不必转场
5. 字幕：旁白关键词已拆好，直接贴时间轴；不录音则全字幕版（把旁白词降级为次要小字）
6. 导出 MP4（H.264 + AAC），文件名 `psycheflow-demo-v1.mp4`
7. 发布：B 站/YouTube（**不公开列出**）→ 把链接写进 README 顶部定位语下一行：
   `> 🎬 3 分钟功能演示：[视频链接]`
