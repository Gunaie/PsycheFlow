# PsycheFlow 教师操作手册

> 适用对象：学校心理老师 / 德育处教师（管理后台使用 + 危机处置）。
> 学生端操作（输入筛查码作答）见文末【附录：学生作答指引】。

---

## 一、登录 / 注册教师账号

1. 浏览器打开系统首页（根地址），选择 **「教师端」** 进入；或直接访问管理后台：`https://你的域名/admin`（内网部署则为 `http://服务器地址:5174/admin`）；
2. 首次使用切到**「注册教师账号」**：填写账号名 + 密码（至少 6 位，两次一致）→ 注册并自动登录；
3. 之后用**账号名 + 密码**登录。注意：教师账号**必须密码登录**，仅凭账号名无法进入（系统安全设计）；
4. 密码在服务器中以加盐哈希（PBKDF2）存储，教师本人也看不到明文。

## 二、创建筛查批次

### 1. 准备名单 CSV

新建文本文件（推荐用 Excel「另存为 CSV UTF-8」），表头与格式如下：

```csv
学号,姓名,年级,班级
20250101,张三,初一,1班
20250102,李四,初一,1班
```

- **必填列**：学号、姓名（表头中英文均可，如 `student_no` / `student_name`）；
- **可选列**：年级、班级（填了才能按班级看进度）；
- 单个批次上限 **500 人**；文件需 UTF-8 编码（带不带 BOM 均可）。

### 2. 建批次步骤

1. 登录后台 → **「创建批次」**；
2. 填批次名称（如 `初一年级秋季普测`）；
3. 勾选量表（可多选）：

| 量表 | 内容 | 适用 |
|---|---|---|
| PHQ-A | 抑郁筛查（9 题） | 快速筛查 |
| SCARED | 焦虑筛查（41 题） | 快速筛查；与 PHQ-A 合并约 10 分钟 |
| SDQ | 长处与困难问卷 | 情绪/行为/社交多维度 |
| MHT | 心理健康诊断测验（100 题） | 全面普测（题量大，建议单独一轮） |

4. 粘贴或上传名单 CSV → 提交。系统为每名学生**自动生成 6 位筛查码**（已剔除易混淆的 0/O/1/I）。

### 3. 发放筛查码

批次创建后，在批次详情页查看每名学生的筛查码，或**导出名单**后线下分发。建议打印成小纸条随知情同意回执一起发放。

## 三、学生施测与进度管理

- 学生打开学生端 `/screening`，输入筛查码（**不区分大小写**，自动转大写）即可作答，**无需注册登录**；
- 计分为**纯规则引擎（不经过 AI）**，结果确定、可复现；
- 每个筛查码**只能完成一次**，完成后再次进入显示"已完成"；
- 批次详情页可实时查看：
  - 总人数 / 已完成 / 未完成；
  - 按班级分组的进度（年级 / 班级）；
  - 各量表严重度分布（无 / 轻度 / 中度 / 重度）。

施测建议错峰进行（如分班分时段），避免全班同时提交。

## 四、查看报告

### 1. 单个学生 PDF 报告

批次详情 → 点开对应学生 → 下载 PDF。报告为单页长图式排版，包含：

- 学生基本信息（来自名单，未填则显示"—"）；
- 各量表总分与严重度、子维度雷达图（SDQ 5 因子 / MHT 8 因子）；
- 测评用时、测评工具介绍；
- AI 生成的发展建议（含兜底话术，不会空白）。

**报告属敏感材料**：仅限心理老师查看；打印件按学校心理档案管理制度保管，不得公开张贴或转发。

### 2. 批次汇总导出

批次详情 → 「导出 CSV」，列为：学号 / 姓名 / 年级 / 班级 / 筛查码 / 状态 / 完成时间。可用于核对完测率、催测未完成学生。

### 3. 关闭批次

施测结束后点**「关闭批次」**：所有筛查码立即失效，防止迟到补测或码外泄后被使用。关闭后统计与报告仍可查看。

## 五、危机处置 SOP（重点，全员必读）

### 1. 系统自动行为（无需教师操作）

当学生作答命中危机关键词（如"不想活了""跳楼""去死"）或 **PHQ-A 第 9 题（自杀意念）单项≥1 分**时，系统**不走 AI、零延迟**：

1. 学生屏幕立即显示红色危机提示 + **12355 共青团青少年心理热线**（24h 免费）；
2. 该学生在批次详情**「危机名单」**中标记（含触发词、量表、分数）；
3. 服务器写双重留痕：`crisis_*.json` 审计文件 + 数据库 AuditLog 表。

### 2. 教师响应链（收到危机名单后）

| 时限 | 动作 |
|---|---|
| **当天** | 心理老师当面/单独约谈该学生，评估现实危险性（勿在班级公开处理） |
| 当天 | 评估为高风险（有计划、有工具、近期事件）→ **立即通知监护人到校**，不得让学生独自离校 |
| 24h 内 | 通知监护人陪同就医或拨打 12355 咨询；危险紧迫时直接 120/110 |
| 1 周内 | 填写学校危机干预记录，安排后续随访（建议每周一次，连续 4 周） |
| 全程 | 不向班主任/其他学生扩散个案信息，传递范围限于"需要知情的最小人群" |

### 3. 每日巡检（心理老师或管理员，建议固定时间）

```bash
# 查看当日危机留痕文件（服务器上执行）
docker exec psycheflow-backend sh -c "ls -la /app/logs/ | grep crisis"

# 备份数据库（产出加密 .db.enc，每日一次）
docker exec -e BACKUP_PASSPHRASE=你的口令 psycheflow-backend \
  uv run python scripts/backup_db.py
```

巡检结果与批次详情「危机名单」核对，两者应一致；不一致（如文件有但名单没有）联系系统管理员。

## 六、常见问题

| 问题 | 处理 |
|---|---|
| 学生说筛查码无效 | 核对是否输错（码中无 0/O/1/I）；批次是否已关闭；是否已用过一次 |
| CSV 上传报"缺少必填列" | 表头必须是 学号/姓名（或 student_no/student_name），不能有空列名 |
| 报告打开空白/下载失败 | 刷新重试；检查是否被浏览器拦截；报告生成需 30-60 秒，按钮会显示"生成中" |
| 学生名单写错/漏人 | 批次无法增删名单——新建一个补充批次即可 |
| 家长索要孩子报告 | 由心理老师导出后线下提供，**不直接给学生/家长系统账号查看他人报告** |
| 系统打开很慢 | 多为 LLM 生成报告中（约 30-60 秒属正常）；施测请错峰 |

## 附录：学生作答指引（可打印张贴）

1. 打开浏览器，输入老师给的网址，进入「心理筛查」页面；
2. 输入老师发的 **6 位筛查码**（字母不区分大小写）；
3. 按真实感受作答，**没有对错好坏之分**，答案只有系统看到；
4. 全部答完点提交，看到"已完成"即可离开；
5. 如果作答过程中心里很不舒服，或出现"寻求帮助"的红色提示——**拨打 12355**（免费，24 小时），或直接找学校心理老师。

> 本次筛查不是考试，结果不影响成绩与评价。
